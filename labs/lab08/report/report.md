11. В режиме Simulation исследован процесс получения IP-адреса по протоколу DHCP.  
    Для анализа использован фильтр DHCP, позволяющий отследить обмен служебными сообщениями между клиентом и сервером.

   ![Передача DHCP-сообщений в режиме моделирования](Screenshot_10.png){ #fig:010 width=80% }

   В процессе наблюдения зафиксирована стандартная последовательность обмена DHCP-сообщениями (DORA):

   - **DHCP Discover** — клиент отправляет широковещательный запрос с адреса 0.0.0.0, пытаясь найти DHCP-сервер в сети;

   - **DHCP Request** — клиент подтверждает выбор предложенного адреса;
   - **DHCP Acknowledgment (ACK)** — сервер окончательно закрепляет IP-адрес за клиентом.

14. В сообщении DHCP Request клиент повторно отправляет выбранный IP-адрес серверу, подтверждая его использование.

   ![Структура DHCP Request сообщения](Screenshot_13.png){ #fig:013 width=80% }

   Это сообщение также передаётся широковещательно, чтобы все DHCP-серверы в сети знали, какой адрес был выбран.

15. В ответ сервер отправляет сообщение DHCP ACK, подтверждая назначение IP-адреса и окончательно завершая процесс конфигурации.

   ![Структура DHCP ACK сообщения](Screenshot_14.png){ #fig:014 width=80% }

# Контрольные вопросы

1. За что отвечает протокол DHCP?  
   Протокол DHCP (Dynamic Host Configuration Protocol) отвечает за автоматическую настройку сетевых параметров устройств в сети. Он позволяет клиентам получать IP-адрес, маску подсети, адрес шлюза по умолчанию, DNS-сервер и другие параметры без ручной настройки, что упрощает администрирование сети и снижает вероятность ошибок.

2. Какие типы DHCP-сообщений передаются по сети?  
   В процессе работы DHCP используются следующие основные типы сообщений:
   - DHCP Discover — широковещательный запрос клиента на поиск DHCP-сервера;
   - DHCP Offer — предложение сервера с параметрами конфигурации;
   - DHCP Request — запрос клиента на получение предложенного адреса;
   - DHCP ACK — подтверждение сервера о выдаче адреса.  

   Дополнительно могут использоваться сообщения DHCP NAK (отказ), DHCP Release (освобождение адреса) и DHCP Inform (запрос дополнительных параметров).

3. Какие параметры могут быть переданы в сообщениях DHCP?  
   В DHCP-сообщениях могут передаваться различные параметры конфигурации:
   - IP-адрес клиента;
   - маска подсети;
   - адрес шлюза по умолчанию;
   - адрес DNS-сервера;
   - доменное имя;
   - время аренды IP-адреса (lease time);
   - адрес DHCP-сервера;
   - дополнительные параметры (опции), например NTP-серверы или WINS.

4. Что такое DNS?  
   DNS (Domain Name System) — это система доменных имён, предназначенная для преобразования символьных имён (например, www.example.com) в IP-адреса и обратно. DNS позволяет пользователям обращаться к ресурсам сети по удобным именам вместо числовых адресов.

5. Какие типы записи описания ресурсов есть в DNS и для чего они используются?  
   В DNS используются различные типы ресурсных записей:
   - A — сопоставляет доменное имя IPv4-адресу;
   - AAAA — сопоставляет доменное имя IPv6-адресу;
   - CNAME — создаёт псевдоним (алиас) для другого доменного имени;
   - MX — указывает почтовый сервер домена;
   - NS — определяет DNS-серверы, обслуживающие домен;
   - PTR — используется для обратного разрешения (IP → имя);
   - TXT — хранит произвольную текстовую информацию (например, для SPF или DKIM).  

   Эти записи обеспечивают работу различных сетевых сервисов и позволяют организовать удобную иерархическую систему адресации в сети.
