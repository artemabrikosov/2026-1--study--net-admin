# Выводы по проделанной работе

## Вывод

Между сетью Университета г. Пиза и сетью «Донская» настроен  
GRE VPN-туннель. Для обмена маршрутной информацией использован OSPF.

Доступность узла сети Университета г. Пиза проверена с ноутбука  
администратора сети «Донская» с помощью команд ping и tracert.
