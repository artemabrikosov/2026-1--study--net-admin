# Контрольные вопросы

1. Какая команда используется для просмотра списка VLAN на сетевом устройстве?  
   Для просмотра списка VLAN на коммутаторе Cisco используется команда `show vlan brief`.  
   Она отображает все созданные VLAN, их идентификаторы (VLAN ID), имена и порты, которые принадлежат каждому VLAN. Данная команда позволяет быстро определить структуру виртуальных локальных сетей на коммутаторе и проверить правильность назначения портов.

2. Охарактеризуйте VLAN Trunking Protocol (VTP). Приведите перечень команд с пояснениями для настройки и просмотра информации о VLAN.  
   VLAN Trunking Protocol (VTP) — это протокол управления VLAN, разработанный компанией Cisco, который используется для централизованного управления VLAN в сети коммутаторов. VTP позволяет автоматически распространять информацию о VLAN между коммутаторами, находящимися в одном VTP-домене. Это упрощает администрирование сети, так как VLAN можно создавать и изменять на одном устройстве, после чего изменения автоматически распространяются на остальные.

   Основные режимы работы VTP:
   - **Server** — режим, в котором можно создавать, изменять и удалять VLAN. Информация о VLAN распространяется на другие коммутаторы домена.  
   - **Client** — коммутатор получает информацию о VLAN от сервера, но не может изменять конфигурацию VLAN.  
   - **Transparent** — коммутатор не участвует в синхронизации VLAN, но может пересылать VTP-сообщения дальше.

   Основные команды настройки и просмотра:
   - `vtp domain <имя>` — задаёт имя VTP-домена.  
   - `vtp mode server` — переводит коммутатор в режим VTP-сервера.  
   - `vtp mode client` — переводит коммутатор в режим VTP-клиента.  
   - `vtp password <пароль>` — устанавливает пароль для VTP-домена.  
   - `vlan <номер>` — создаёт VLAN.  
   - `name <имя>` — задаёт имя VLAN.  
   - `show vtp status` — отображает информацию о состоянии VTP.  
   - `show vlan brief` — выводит список VLAN и назначенные им порты.

3. Охарактеризуйте Internet Control Message Protocol (ICMP). Опишите формат пакета ICMP.  
   Internet Control Message Protocol (ICMP) — это служебный протокол сетевого уровня, используемый для передачи диагностических сообщений и уведомлений об ошибках в IP-сетях. ICMP применяется для проверки доступности узлов сети и анализа состояния сетевых соединений. Наиболее известный пример использования ICMP — команда `ping`, которая отправляет ICMP Echo Request и получает ответ Echo Reply.

   Формат пакета ICMP включает следующие основные поля:
   - **Type** — тип сообщения (например, Echo Request или Echo Reply);  
   - **Code** — дополнительная информация о типе сообщения;  
   - **Checksum** — контрольная сумма для проверки целостности пакета;  
   - **Identifier** — идентификатор сообщения;  
   - **Sequence Number** — порядковый номер пакета;  
   - **Data** — область данных переменной длины.

4. Охарактеризуйте Address Resolution Protocol (ARP). Опишите формат пакета ARP.  
   Address Resolution Protocol (ARP) — это протокол канального уровня, предназначенный для определения MAC-адреса устройства по известному IP-адресу в пределах одной локальной сети. Когда устройство хочет отправить пакет другому узлу сети, оно сначала определяет MAC-адрес получателя с помощью ARP-запроса. Узел с соответствующим IP-адресом отправляет ARP-ответ со своим MAC-адресом.

   Формат ARP-пакета включает следующие поля:
   - **Hardware Type (HTYPE)** — тип аппаратной среды (например, Ethernet);  
   - **Protocol Type (PTYPE)** — тип сетевого протокола (например, IPv4);  
   - **Hardware Address Length (HLEN)** — длина аппаратного адреса;  
   - **Protocol Address Length (PLEN)** — длина сетевого адреса;  
   - **Operation (OPER)** — тип операции (запрос или ответ);  
   - **Sender Hardware Address (SHA)** — MAC-адрес отправителя;  
   - **Sender Protocol Address (SPA)** — IP-адрес отправителя;  
   - **Target Hardware Address (THA)** — MAC-адрес получателя;  
   - **Target Protocol Address (TPA)** — IP-адрес получателя.

5. Что такое MAC-адрес? Какова его структура?  
   MAC-адрес (Media Access Control Address) — это уникальный физический адрес сетевого интерфейса, назначаемый производителем оборудования. Он используется на канальном уровне модели OSI для идентификации устройств в локальной сети.

   MAC-адрес состоит из 48 бит (6 байт) и обычно записывается в шестнадцатеричном формате, например: `00:1A:2B:3C:4D:5E`.

   Структура MAC-адреса:
   - **Первые 24 бита (OUI — Organizationally Unique Identifier)** — идентификатор производителя устройства.  
   - **Последние 24 бита** — уникальный номер сетевого интерфейса, присваиваемый производителем.

   Такая структура обеспечивает уникальность каждого сетевого устройства в пределах глобальной сети.
